## Задачи на будущее

### UI: Тёмная тема (низкий приоритет)

**Проблема:** Qt не подхватывает системную тёмную тему на Linux без дополнительных пакетов (например, `adwaita-qt6` на GNOME).

**Решение:**
1. Добавить переключатель темы в настройках («Светлая / Тёмная / Системная»)
2. Для «Системная» — читать системную тему через D-Bus freedesktop color-scheme portal (QtDBus, без внешних зависимостей)
3. Fallback на QPalette по яркости, затем ручной выбор
4. Сохранение выбора в QSettings

**Почему не просто детекция по цвету:** Детекция по `QPalette` работает только если Qt уже подхватил системную тему. Правильный способ — читать системную тему через D-Bus портал.

### UX: Автопереключение на CPU-режим

**Проблема:** Приложение требует ручного переключения на CPU-режим при отсутствии GPU.

**Решение:** Автодетекция отсутствия GPU и автоматическое включение CPU-режима.
