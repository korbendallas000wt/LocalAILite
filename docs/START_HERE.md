# LocalAILite — для новой модели

> Точка входа для быстрого понимания проекта и вхождения в разработку.

## Что это за проект

**LocalAILite** — локальный AI-ассистент для Linux:
- 💬 **Чат с Ollama** — локальные LLM (qwen2.5-coder, llama3 и др.)
- 🎨 **Генерация изображений** — SDXL через Diffusers (с чекпоинтами и resume)
- 🖼️ **Визуальный редактор** — подготовка изображений для img2img

**Платформа:** Linux (5 дистрибутивов), PyQt6, Python 3.10+  
**Ветки:** `dev` (активная разработка), `main` (стабильная, для пользователей)

## Workflow разработки

**Повседневка:**
1. Правим в живом проекте (`~/Scripts/LocalAILite/`)
2. `git add` → `git commit` → `git push` (в ветку `dev`)

**Релиз (раз в 1-2 недели):**
1. Зеркалим стабильное из проекта в Repo/
2. Коммит в `main`
3. `git push`

## Ключевые архитектурные решения

- **Идемпотентность:** повторный запуск чинит большинство проблем
- **Путь B:** усиливаем диагностику, не меняем рабочий алгоритм
- **Двухуровневые проверки:** быстрые в шагах + глубокие в финале
- **Версионно-специфичные пакеты:** PyQt6 в openSUSE привязан к версии Python

## Советы

- Не бойся экспериментировать — идемпотентность работает
- Проверяй гипотезы экспериментально
- Не меняй рабочий алгоритм без нужды
- Логируй всё — диагностируемость слабая
- Доверяй Корбену — он хорошо знает систему
