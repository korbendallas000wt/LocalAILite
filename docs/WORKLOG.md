# Журнал разработки LocalAILite

## Сессия 2026-08-22: Сохранение/загрузка чатов + режимы работы + фикс бага очистки

### Что сделано
1. **Модуль экспорта чатов (`core/chat_exporter.py`)**:
   - Сохранение в JSON (для машины: точное воспроизведение, настройки, stats) и TXT (для человека: markdown с разделителями).
   - Генерация имён файлов: дата + санитизированный заголовок (с fallback на timestamp).
   - Автогенерация заголовка через LLM (опционально, через настройки).

2. **Режимы работы чата (`ui/settings_panel.py`, `ui/tabs/ollama_tab.py`)**:
   - Добавлены радиокнопки: "Новый", "Продолжить", "Изменить".
   - Логика блокировки UI: в режиме "Продолжить" настройки заблокированы (чтобы не ломать контекст), в "Изменить" — активны.
   - Загрузка чата из JSON через кнопку `📂` с применением оригинальных настроек.

3. **Исправление критического бага**:
   - Кнопка "+ Новый чат" теперь корректно ждёт завершения асинхронного сохранения перед очисткой истории (добавлен флаг `_pending_clear_after_save`). Раньше чат очищался мгновенно, и сохранялся пустым.

4. **Документация**:
   - Добавлен `chat_exporter.py` в `docs/STRUCTURE.md`.
